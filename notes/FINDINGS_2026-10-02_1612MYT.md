## Tracking bug 1: ViewContent script is broken (confirmed)
Product pages output:
```
<script id="meta_pixel_inline-js-after">Meta Pixel Event Code -->
    fbq('set', 'agent', 'wordpress_0-7.1.2-5.2.2', '991524961836380');fbq('track', 'ViewContent', {...
```
The leading `<!--` is missing, so the line is a JS syntax error and the browser
`ViewContent` never fires. Source (WP 7.1 inline-script handling vs LiteSpeed JS
optimisation) not yet isolated.

## Tracking bug 2: cached pages share one eventID (confirmed)
Three cached fetches of `/product/milk-lotion-300ml/` all contained
`"eventID": "1bd34e73-3828-49b3-97e2-66a7f86de24f"`. Every visitor sends the same
browser eventID while server (CAPI) events only fire on cache misses → broken
deduplication. Possible cause of red "AddToCart — Event not processed" rows (unconfirmed).
